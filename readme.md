# Вкусно и просто — агрегатор рецептов

Учебный проект по учебной практике **УП.09.01** (ПМ.09 «Проектирование, разработка
и оптимизация веб-приложений»). Полноценное веб-приложение: каталог рецептов,
регистрация и авторизация, личный кабинет, административная панель и интеграция
с внешним API.

---

## Что умеет сайт

**Для посетителя**
- каталог из 35 рецептов с фотографиями;
- поиск по названию, фильтры по категории, кухне и сложности, сортировка;
- страница рецепта: состав с количествами, пошаговая инструкция, отзывы и рейтинг;
- категории блюд и кухни мира со статистикой;
- новости проекта, страница «О проекте», форма обратной связи;
- работа с внешним API TheMealDB: поиск, случайный рецепт, категории.

**Для пользователя (после входа)**
- личный кабинет: профиль, избранное, свои отзывы;
- добавление рецептов в избранное и удаление из него;
- публикация отзывов с оценкой от 1 до 5;
- редактирование профиля и смена пароля.

**Для администратора**
- панель со сводкой: количество рецептов, пользователей, отзывов, сообщений;
- просмотр **всех 11 таблиц** базы данных;
- добавление, изменение и удаление записей в каждой таблице;
- просмотр **5 представлений** (VIEW) в режиме чтения;
- отметка сообщений обратной связи как прочитанных.

## Установка и запуск

### 1. Разместить файлы
Скопируйте папку проекта в каталог веб-сервера:

```
D:\xamp\htdocs\про1
```

### 2. Запустить Apache и MySQL
Откройте **XAMPP Control Panel** и нажмите **Start** напротив `Apache` и `MySQL`.

### 3. Создать базу данных
Вариант А — через phpMyAdmin:
1. откройте `http://localhost/phpmyadmin`;
2. вкладка **SQL**;
3. вставьте содержимое файла `sql/schema.sql` и нажмите **Вперёд**.

Вариант Б — из командной строки:

```bash
D:\xamp\mysql\bin\mysql.exe -u root < sql/schema.sql
```

Вариант В — если база ещё не создана, сначала выполните:

```sql
CREATE DATABASE recipe_aggregator CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 4. Наполнить базу данными
Из командной строки в папке проекта:

```bash
D:\xamp\php\php.exe tools/seed.php
```

Скрипт создаст категории, кухни, 35 рецептов с составом и инструкциями,
пользователей, отзывы, избранное и новости.
Повторный запуск очищает таблицы и наполняет их заново.

### 5. Проверить настройки подключения
Файл `inc/config.php`:

```php
define('DB_HOST', '127.0.0.1');
define('DB_PORT', '3306');
define('DB_NAME', 'recipe_aggregator');
define('DB_USER', 'root');
define('DB_PASS', '');       // в XAMPP пароль по умолчанию пустой
```

Параметры можно переопределить переменными окружения `DB_HOST`, `DB_NAME`,
`DB_USER`, `DB_PASS` — удобно при переносе на другой сервер.

### 6. Открыть сайт

```
http://localhost/про1/
```

Если папка называется иначе, адрес будет `http://localhost/<имя папки>/`.

Альтернатива без Apache (встроенный сервер PHP):

```bash
D:\xamp\php\php.exe -S 127.0.0.1:8000 -t .
```

затем открыть `http://127.0.0.1:8000/`.

## База данных

11 таблиц: `roles`, `users`, `categories`, `cuisines`, `recipes`, `ingredients`,
`recipe_ingredients`, `favorites`, `reviews`, `news`, `messages`.

5 представлений:

| Представление | Назначение |
|---|---|
| `v_recipe_catalog` | карточка рецепта с рейтингом и числом ингредиентов |
| `v_top_recipes` | рецепты по популярности (добавления в избранное) |
| `v_category_stats` | количество рецептов и средний рейтинг по категориям |
| `v_user_activity` | активность пользователей: избранное и отзывы |
| `v_unread_messages` | непрочитанные сообщения с днями ожидания |

## Внешний API

Используется открытый REST API [TheMealDB](https://www.themealdb.com/api.php).

| Метод | Назначение | Где используется |
|---|---|---|
| `search.php?s=` | поиск блюд по названию | страница «API», главная |
| `random.php` | случайное блюдо | блок на главной, страница «API» |
| `categories.php` | список категорий | страница «API» |

Запросы выполняются на стороне браузера через `fetch()` — если интернет
недоступен, страница показывает сообщение об ошибке, а локальный каталог
продолжает работать из своей базы.
